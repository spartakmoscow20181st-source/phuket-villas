Режим редактирования фото

Нужен ключ доступа GitHub — он хранится только на этом устройстве. Как получить:

  1. github.com → фото профиля → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → phuket-villas.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate token, скопируйте и вставьте сюда.
